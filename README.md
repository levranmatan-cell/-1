# הבנים של ז׳1 - שרת אונליין

הקבצים כאן: `index.html` (המשחק), `server.js` (השרת), `package.json`.

## להעלות ל-Render (חינם)

1. פותחים חשבון ב-github.com (אם אין), ויוצרים Repository חדש בשם `ze1`.
2. בעמוד של ה-Repository: Add file ← Upload files. גוררים פנימה את כל הקבצים מהתיקייה הזאת (`index.html`, `server.js`, `package.json`) ולוחצים Commit.
3. נכנסים ל-render.com ונרשמים עם GitHub.
4. New ← Web Service ← בוחרים את ה-Repository `ze1`.
5. מגדירים:
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free
6. לוחצים Create Web Service ומחכים כמה דקות.
7. מקבלים כתובת כמו `https://ze1-xxxx.onrender.com`. זה הקישור למשחק. שולחים אותו לחברים.

## איך משחקים

- אחד פותח את הקישור, בוחר דמות, לוחץ "אונליין עם החברים" ← "פתח חדר" ומקבל קוד.
- כל השאר פותחים את אותו קישור, בוחרים דמות, ל"אונליין עם החברים" ← מקלידים את הקוד ← "הצטרף".
- המארח לוחץ "התחל משחק".

## כדאי לדעת

- ב-Render החינמי השרת נרדם אחרי 15 דקות בלי שימוש. הכניסה הראשונה אחרי זה לוקחת בערך דקה.
- המארח צריך להשאיר את הלשונית פתוחה ופעילה. אם עוברים ללשונית אחרת, המשחק אצלו נעצר.
- בלי חשבון ובלי התקנה: כל מי שיש לו את הקישור והקוד יכול להצטרף.
